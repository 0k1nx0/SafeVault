# SafeVault

SafeVault is a secure desktop password manager built with Electron. It stores credentials locally in an encrypted vault and supports OTP-based account recovery.

## Team

- [Swastika Guleria](https://github.com/guleriaswastika)
- [Karan Goyal](https://github.com/karangoyal09)
- [0k1nx0](https://github.com/0k1nx0)

## Features

- Master password protected vault
- AES-256-CBC encrypted local storage
- Password strength checker
- Random password generator
- OTP-based recovery flow
- Auto-lock on inactivity
- Windows installer packaging

## Setup

Copy `sms-config.example.js` to `sms-config.js` and add your 2Factor API key before using SMS OTP recovery.
